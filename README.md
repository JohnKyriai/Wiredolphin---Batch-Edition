**WireDolphin Batch Edition**

A lightweight Windows networking multitool built with Batch.

Features:

 - IP Pinger, test connectivity to a host. It uses the built in **'ping'** command.
  <img width="621" height="415" alt="image" src="https://github.com/user-attachments/assets/f8829bff-04ee-44f0-b4cc-dd310aaa9904" />


-  Identity Tools, display your Windows username and hostname. This one has two options, you can either use the **'whoami'** command or the **'hostname'** command.
-  <img width="627" height="404" alt="image" src="https://github.com/user-attachments/assets/19d964fc-a5df-497f-a5c6-9ff1882cab0b" />


-  DNS Lookup, look up domain information. This the **'nslookup'** command.
-  <img width="619" height="415" alt="image" src="https://github.com/user-attachments/assets/72466a02-9a37-4a96-a290-00baf03c565a" />


-  Network Statistics, view connections and listening ports. This uses the **'netstat -ano'** command.

-  Protocol Statistics, view network protocol counters. This is uses the **'netstat -s'** command.

-  FTP Client, connect to FTP servers. This uses the FTP features in Windows and wraps them around a shell.
-  <img width="622" height="417" alt="image" src="https://github.com/user-attachments/assets/3fe85aaf-7a2f-470f-abca-0d8647aeccac" />


Compatibility:

- Windows XP
- Windows Vista
- Windows 7
- Windows 8/8.1
- Windows 10
- Windows 11

- *Windows 2000 could work but I haven't tested it out*

**HOW TO USE THIS:**

-Download *Wiredolphin.bat*.

-Double click the file to launch it.

-And you are in!
